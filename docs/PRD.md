# 拾页 / Reading Garden 产品需求文档

## 1. 产品定位

**拾页 / Reading Garden** 是个人阅读知识库 + 轻量读书社区。

产品首先帮助用户整理自己的书、阅读记录、摘录与感想；在用户明确选择公开或分享不可猜测链接后，再提供轻量的笔记交流能力。外部平台只作为资料入口，不取代本地阅读知识库。

## 2. 目标用户

| 用户类型 | 核心需求 | 主要使用路径 |
| --- | --- | --- |
| 个人读者 | 集中管理读过的书、阅读状态与零散感想 | 登录 → 管理书架 → 记录笔记 |
| 深度阅读者 | 保留章节、页码、原文摘录与长篇反思 | 创建书籍 → 记录多段引用 → 关联标签 |
| 分享者 | 将经过筛选的读书笔记公开或定向分享 | 编辑笔记 → 选择 public/unlisted → 分享链接 |
| 资料整理者 | 导入 PDF、TXT、Markdown 等资料并建立索引 | 上传文件 → 校验与解析 → 生成待整理记录 |
| 访客 | 无需登录浏览公开笔记与公开个人主页 | 浏览社区 → 打开笔记或主页 |

## 3. 核心场景

| 场景 | 用户目标 | 关键流程 | 成功结果 | 优先级 |
| --- | --- | --- | --- | --- |
| 管理书籍 | 建立并维护个人书架 | 新建/编辑书籍，记录状态与阅读进度 | 书籍只对所有者可见，状态可检索 | P0 |
| 记录摘要与感想 | 将阅读中的摘录和反思沉淀为笔记 | 创建笔记、添加引用与标签、选择可见性 | 笔记内容、来源和权限状态正确保存 | P0 |
| 分享公开笔记 | 让其他人阅读经过筛选的内容 | 将笔记设为 public，或在需要时生成 unlisted 链接 | 公开内容可访问，私密字段和附件不泄露 | P0 |
| 导入资料 | 减少手工录入，建立后续整理入口 | 上传 PDF/TXT/Markdown，校验并生成导入任务 | 成功生成可追踪记录；失败有明确原因 | P0 |
| 浏览社区 | 发现其他读者的公开笔记 | 浏览公开流、个人主页，进行评论和点赞 | 只出现允许公开的内容，互动可管理 | P1 |
| 外部剪裁 | 从浏览器或微信读书带入摘录 | 主动选择内容，经服务端适配器导入 | 来源可追踪，不读取未授权数据 | P2 |

## 4. 功能优先级

### P0：首版必须有

- 书籍 CRUD。
- 笔记 CRUD。
- 登录、退出与基础会话管理。
- 笔记可见性：`private`、`public`、`unlisted`。
- 个人范围内的搜索。
- PDF、TXT、Markdown 导入。
- 所有用户数据表启用 RLS；私有附件使用私有 Storage bucket。

### P1：形成轻量社区与整理闭环

- 公开笔记流。
- 个人主页。
- 评论。
- 点赞。
- 来源追踪。
- 重复导入检测。

### P2：外部入口与智能增强

- 微信读书只读导入。
- Chrome 扩展主动剪裁。
- OCR。
- 智能摘要。
- 关注与共读。

## 5. 页面清单与验收条件

| 路径 | 页面目标 | 验收条件 |
| --- | --- | --- |
| `/` | 产品入口与个人阅读概览 | 未登录用户可看到产品定位与公开入口；登录用户可看到自己的书架摘要和快捷操作；页面不得渲染任何私有书籍、笔记或文件；主导航可到达规定页面。 |
| `/library` | 管理个人书架 | 未登录访问会进入登录流程；登录用户可查看、搜索、筛选、新建和编辑自己的书籍；只能看到自己的书籍；空状态、加载态和错误态均有明确反馈。 |
| `/books/[id]` | 查看一本书及其阅读资料 | 所有者可看到书籍元数据、阅读记录和关联笔记；非所有者只能看到明确公开的书籍元数据和公开笔记；私有文件与阅读记录永不随公开书籍展示；无权访问返回 404/403 而非泄漏内容。 |
| `/notes/[id]` | 阅读一篇笔记 | `private` 仅所有者可读；`public` 可由访客读取允许展示字段；`unlisted` 需不可猜测链接访问，且不出现在公共列表；引用、标签、评论和附件均遵循父笔记权限。 |
| `/write` | 创建或编辑笔记 | 仅登录用户可访问；支持标题、正文、引用、标签和可见性选择；保存前进行服务端校验；未选择可见性时默认 `private`；保存失败显示真实原因，不展示成功状态。 |
| `/community` | 浏览公开笔记 | 仅列出 `public` 笔记；不返回 `private`/`unlisted` 内容、私有附件或阅读记录；支持分页/加载更多；空状态与无权限状态清晰。 |
| `/profile/[id]` | 查看用户公开主页或自己的主页 | 访客仅看到公开用户的允许展示字段和公开笔记；所有者可看到自己的管理入口；私密书籍、私密笔记、阅读记录和导入任务不展示；不可见主页返回 404。 |
| `/import` | 导入个人阅读资料 | 仅登录用户可访问；接受 PDF、TXT、Markdown；校验类型、大小和内容；显示导入任务状态、错误原因和重试入口；无重复导入时不创建重复记录；未核验的外部来源不得显示虚假成功。 |
| `/settings` | 管理账户与隐私设置 | 仅登录用户可访问；可编辑公开资料与默认笔记可见性；可查看扩展配对与外部导入的可用状态；保存后不得回显完整密钥或 Service Role Key；退出登录后会话失效。 |

## 6. 权限与隐私底线

- 默认创建的内容为私密，公开必须由用户明确操作。
- Public 只代表允许访客读取允许展示的字段，不代表公开原始附件、阅读记录、导入任务或完整书籍内容。
- Unlisted 使用不可猜测 token 分享，不进入公共列表，但不是强保密机制，不能替代登录鉴权或 RLS。
- 所有权限判断以服务端和数据库策略为准，客户端隐藏按钮不构成权限控制。

## 7. 首版明确不做

- 不公开整本版权内容。
- 不默认公开原始 PDF 与阅读记录。
- 不依赖未授权微信读书接口。
- 不做重社交与实时协作。
